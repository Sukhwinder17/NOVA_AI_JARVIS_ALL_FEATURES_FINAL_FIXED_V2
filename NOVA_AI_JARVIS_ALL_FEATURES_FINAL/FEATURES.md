# NOVA feature map

## Conversation
- Persistent conversation history
- Typed commands
- Groq default
- xKiro fallback
- Explicit Gemini provider
- Local memory context

## NOVA actions
- App launching
- Chrome/browser navigation
- Browser automation
- Whole-PC Everything search
- Open recent file by number/name
- File read/write/move/copy/rename/delete/list/find
- File processing
- Code write/edit/run/build
- Developer agent
- YouTube
- Video playback
- Weather
- Flights
- Web search/news/research/price/compare
- Reminders
- Messaging
- Desktop controls
- Computer settings
- System status
- Background monitoring
- Undo
- Memory
- Screen vision
- Camera vision
- Clipboard intelligence
- Invoice rendering

## Voice
- Listen / stop listening
- Groq speech-to-text
- Native Windows speech output
- Speaking state drives the sphere animation
- Optional Ctrl+Space push-to-talk
- Mark-LV wake-word engine retained as an optional source module

## UI
- No Streamlit
- No navigation sidebar
- No CPU/GPU dashboard as the main screen
- Persistent chat
- Animated 3D-style sphere / reactor visual
- Provider selector
- Visible listening/thinking/speaking states
- Real activity status

## External source integration
The uploaded JARVIS Prompt Pack describes the feature progression from baseline voice + shell + file graph through speech, graph reasoning, camera, real panels, messaging, inbox, invoices, push-to-talk, wake word, agents and portability. NOVA incorporates the applicable desktop capabilities while adapting the visual identity and provider layer to NOVA.
